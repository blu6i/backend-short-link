Учебный проект для создания коротких ссылок, управления ими в личном кабинете и сбора статистики переходов.

## 🛠 Технологический стек

Проект построен на современных технологиях и рассчитан на асинхронную работу:

* **Бэкенд:** Python 3.12+, FastAPI
* **База данных (СУБД):** PostgreSQL
* **ORM и Миграции:** SQLAlchemy, Alembic
* **Кэширование и Брокер сообщений:** Redis
* **Фоновые задачи:** Celery
* **Валидация данных и конфигурация:** Pydantic, Pydantic-Settings
* **Аутентификация:** JWT (с хранением в `Set-Cookie`)
* **Менеджмент зависимостей:** `uv`
* **Инфраструктура:** Docker, Docker Compose
* **Тестирование:** Pytest, HTTPX

## ⚙️ Ключевой функционал

1. **Гостевые ссылки:** Быстрое сокращение ссылок без регистрации (сохраняются исключительно в Redis с заданным временем жизни TTL).
2. **Личный кабинет:** Регистрация, авторизация и возможность управлять своими постоянными ссылками (удаление, просмотр списка). Гарантия уникальности ссылок пользователя на уровне БД.
3. **Мгновенный редирект:** Кэширование связок в Redis для максимальной скорости перенаправления. Поддержка «мягкого удаления» (Soft Delete).
4. **Асинхронная аналитика:** Сбор статистики по переходам (дата, анонимный IP). Сбор происходит в фоновом режиме через Celery, не замедляя работу самого эндпоинта редиректа.
