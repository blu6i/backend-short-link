# 📖 Документация API: Сервис сокращения ссылок (v1)

Данный документ описывает доступные эндпоинты системы, форматы запросов и ответов.

---

## 👥 USER API

Управление пользователями и аутентификация.  
**Базовый путь:** `/users`

### 1. Создание пользователя (Регистрация)

Регистрирует нового пользователя. После успешной регистрации устанавливает JWT токены в куки и возвращает данные пользователя.

- **URL:** `/`
- **Метод:** `POST`
- **Авторизация:** Не требуется

**Параметры запроса (JSON):**

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `email` | `string` | **Обязательное.** Почта пользователя |
| `password` | `string` | **Обязательное.** Пароль (минимум 8 символов) |
| `username` | `string` | **Обязательное.** Имя пользователя (от 4 до 16 символов) |

**Ответы:**

- **`201 Created`**
  - **Заголовки (Cookies):**
    - `Set-Cookie: access_token` (HttpOnly, срок жизни 15 минут)
    - `Set-Cookie: refresh_token` (HttpOnly, срок жизни 7 дней)
  - **Тело (JSON):**

    ```json
    {
      "email": "user@example.com",
      "username": "nickname"
    }
    ```

- **`400 Bad Request`**: Неверно введена почта, имя пользователя или пароль.
- **`409 Conflict`**: Нарушение уникальности (email или username уже занят).

---

### 2. Авторизация (Логин)

Авторизует существующего пользователя.

- **URL:** `/login`
- **Метод:** `POST`
- **Авторизация:** Не требуется

**Параметры запроса (JSON):**

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `email` | `string` | **Обязательное.** Почта пользователя |
| `password` | `string` | **Обязательное.** Пароль |

**Ответы:**

- **`200 OK`**
  - **Заголовки (Cookies):**
    - `Set-Cookie: access_token` (HttpOnly, 15 мин)
    - `Set-Cookie: refresh_token` (HttpOnly, 7 дней)
  - **Тело (JSON):** (данные профиля)
- **`400 Bad Request`**: Неверные учетные данные.

---

### 3. Обновление профиля

Частично обновляет данные текущего авторизованного пользователя.

- **URL:** `/me`
- **Метод:** `PATCH`
- **Авторизация:** Требуется (`access_token` в куках)

**Параметры запроса (JSON):**

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `email` | `string` | *Опционально.* Новая почта пользователя |
| `password` | `string` | *Опционально.* Новый пароль (мин. 8 символов) |
| `username` | `string` | *Опционально.* Новое имя пользователя |

**Ответы:**

- **`200 OK`**: Успешное обновление, возвращает обновленный профиль (JSON).
- **`400 Bad Request`**: Ошибка валидации данных.
- **`401 Unauthorized`**: Токен отсутствует или недействителен.
- **`409 Conflict`**: Email или username уже заняты.

---

### 4. Обновление токенов

Выдает новую пару токенов (refresh и access) по действующему refresh-токену.

- **URL:** `/new_tokens`
- **Метод:** `POST`
- **Авторизация:** Требуется (`refresh_token` в куках)

**Ответы:**

- **`200 OK`**: Устанавливает новые `access_token` и `refresh_token` в заголовке `Set-Cookie`.
- **`401 Unauthorized`**: Невалидный или истекший refresh-токен.

---

### 5. Удаление пользователя

Полностью удаляет профиль пользователя.

- **URL:** `/me`
- **Метод:** `DELETE`
- **Авторизация:** Требуется

**Ответы:**

- **`204 No Content`**: Успешное удаление.
- **`401 Unauthorized`**: Токен отсутствует или недействителен.

## 🔗 URL API

Управление сокращенными ссылками.  
**Базовый путь:** `/urls`

### 1. Создание ссылки

Создает новую короткую ссылку для авторизованного пользователя.

- **URL:** `/`
- **Метод:** `POST`
- **Авторизация:** Требуется

**Параметры запроса (JSON):**

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `url` | `string` | **Обязательное.** Длинная (оригинальная) ссылка для сокращения |

**Ответы:**

- **`201 Created`**
  - **Тело (JSON):**

    ```json
    {
      "short_url": "AbC12x"
    }
    ```

- **`401 Unauthorized`**: Требуется авторизация.
- **`409 Conflict`**: Пользователь уже сокращал эту ссылку ранее (нарушение уникальности).

---

### 2. Список ссылок пользователя

Возвращает список всех коротких ссылок, созданных текущим пользователем.

- **URL:** `/list`
- **Метод:** `GET`
- **Авторизация:** Требуется

**Ответы:**

- **`200 OK`**
  - **Тело (JSON):**

    ```json
    [
      { "short_url": "AbC12x" },
      { "short_url": "xyz789" }
    ]
    ```

- **`401 Unauthorized`**: Требуется авторизация.

---

### 3. Мягкое удаление ссылки

Удаляет (деактивирует) ссылку пользователя. При переходе по ней в будущем будет выдаваться ошибка.

- **URL:** `/{short_url}`
- **Метод:** `DELETE`
- **Авторизация:** Требуется

**Параметры пути (Path):**

- `short_url` — короткий идентификатор ссылки

**Ответы:**

- **`204 No Content`**: Успешное удаление.
- **`401 Unauthorized`**: Требуется авторизация.

---

### 4. Статистика переходов по ссылке

Получение аналитики по переходам для конкретной ссылки.

- **URL:** `/{short_url}/info`
- **Метод:** `GET`
- **Авторизация:** Требуется (Только владелец ссылки может видеть статистику)

**Параметры пути (Path):**

- `short_url` — короткий идентификатор ссылки

**Параметры запроса (Query):**

- `type` — масштаб анализа. Доступные значения: `DAY`, `MONTH`, `YEAR`.

**Ответы:**

- **`200 OK`**: Возвращает массив объектов. Структура зависит от фильтра `type`:
  - **`DAY`** (По часам): `[ { "HOUR": "14:00", "COUNT": 5 }, ... ]`
  - **`MONTH`** (По дням): `[ { "DAY": "2023-10-15", "COUNT": 42 }, ... ]`
  - **`YEAR`** (По месяцам): `[ { "MONTH": "2023-10", "COUNT": 300 }, ... ]`
- **`401 Unauthorized`**: Пользователь не авторизован.
- **`403 Forbidden`**: Попытка посмотреть статистику чужой ссылки.
- **`404 Not Found`**: Ссылка не найдена в базе данных.

## 🚀 REDIRECT API

Обработка переходов по коротким ссылкам.  
**Базовый путь:** `/` (Корень сервера)

### 1. Перенаправление (Redirect)

Осуществляет перенаправление (редирект) по сохраненному короткому ID на оригинальный URL.

- **URL:** `/{short_url}`
- **Метод:** `GET`
- **Авторизация:** Не требуется

**Параметры пути (Path):**

- `short_url` — короткий идентификатор ссылки

**Ответы:**

- **`307 Temporary Redirect`**:
  - **Заголовки:** `Location: <Оригинальный URL>`
- **`404 Not Found` / `410 Gone`**: Если ссылка не существует, истекла, или была удалена владельцем (деактивирована).
